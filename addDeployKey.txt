1. If you already have the .ssh folder in your pc, just skip this step.

mkdir -p ~/.ssh
chmod 700 ~/.ssh


2. Get the keys from me 

Save the private key as:
~/.ssh/minirt_deploy

and the public key as:
~/.ssh/minirt_deploy.pub

Then do:
chmod 600 ~/.ssh/minirt_deploy
chmod 600 ~/.ssh/minirt_deploy.pub


3. Set the SSH Config

nano ~/.ssh/config

Put:
Host github-minirt
    HostName github.com
    User git
    IdentityFile ~/.ssh/minirt_deploy
    IdentitiesOnly yes

Then do:
chmod 600 ~/.ssh/config


4. Test the key
ssh -T git@github-minirt


5. Set up the repository
git clone git@github-minirt:jbdmc42/MiniRT.git

cd MiniRT

git remote -v

If it shows:
origin  git@github-minirt:jbdmc42/MiniRT.git (fetch)
origin  git@github-minirt:jbdmc42/MiniRT.git (push)

it should be correct.
